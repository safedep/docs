## Ask for help

Include these details in your question. Remove sensitive information first.

- What you want to do, the command you ran, and the expected and actual result
- Your operating system and its version
- Your Vet version, from `vet version`
- The related manifest or configuration files
- The error message and the debug log, in code blocks

To get the debug log:

```bash
# Show debug logs in the terminal
vet scan -D /path/to/repo -l- -d

# Write the debug log to a file that you can share
vet scan -D /path/to/repo -l /tmp/vet.log -d
```
