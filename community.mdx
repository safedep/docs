## Ask for help

Include these details in your question. Remove sensitive information first.

- What you want to do, the command you ran, and the expected and actual result
- Your operating system and its version
- The tool version, from `vet version`, `pmg version`, `gryph version`, `xbom version` or `safedep version`
- The related manifest or configuration files
- The error message and the debug log, in code blocks

To get more detailed log output:

```bash
# vet: show the debug log in the terminal, or write it to a file
vet scan -D /path/to/repo -l- -d
vet scan -D /path/to/repo -l /tmp/vet.log -d

# PMG: show the debug log, and write the logs to a file
pmg --debug --log /tmp/pmg.log npm install <package>

# Gryph: show verbose output, or check the installation
gryph --verbose <command>
gryph doctor

# xBom: show verbose output
xbom --verbose <command>

# SafeDep CLI: show verbose error details
safedep --verbose <command>
```
