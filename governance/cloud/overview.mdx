SafeDep Cloud is the software supply chain security platform built on SafeDep's open source tools. Every feature of [PMG](/package-security/pmg/overview), [Vet](/governance/vet/overview), and [xBom](/governance/xbom/overview) is open source. You can read the code and verify what each tool does before you run it.

One developer needs only the tools. A team can deploy the tools by hand and write its own reporting. SafeDep Cloud does this work for a team or an organization:

- **Control plane.** Connect the tools on developer machines, CI runners, and agent sandboxes to one tenant. [Endpoint Hub](/governance/cloud/endpoint-hub/overview) shows each endpoint and what the tools on it blocked or found.
- **Data lake.** Keep package events, scan results, policy violations, and AI tool inventory in one place. Query them with [SQL](/reference/sql-query) from the console, the `safedep` CLI, or the API. An [AI agent](/governance/cloud/talk-to-safedep) can use the same queries to answer questions about your supply chain.
- **Intelligence layer.** Run [on-demand scans](/package-security/scan/overview) of packages, extensions, and repositories, and get the [Threat Intel Feed](/threat-intel/overview).

You own your data. The [SafeDep Cloud API](/reference/api-introduction) gives you full access to it, so you can build your own integrations. See [SafeDep Plans](/governance/cloud/plans) for what each plan includes.
