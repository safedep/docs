Every feature of PMG, Vet, xBom, and Gryph is in the open source release. The plans apply to [SafeDep Cloud](/governance/cloud/overview), the control plane, data lake, and intelligence layer for a team or an organization. For prices and monthly allowances, see the [pricing page](https://safedep.io/pricing).

## Open source tools

No account is necessary for these tools.

| Tool | What it does |
| --- | --- |
| [PMG](/package-security/pmg/overview) | Blocks malicious packages at install time. Includes the dependency cooldown, the sandbox, network policy, and kernel enforcement. |
| [Vet](/governance/vet/overview) | Scans repositories, lockfiles, and SBOMs. Applies policy, and discovers AI tools on an endpoint. |
| [xBom](/governance/xbom/overview) | Generates a bill of materials from code. |
| [Gryph](/ai-security/gryph-overview) | Records what an AI coding agent reads, writes, and runs. |

PMG and Vet check packages against SafeDep's [malicious package intelligence](/concepts/malicious-package) through a free community API.
