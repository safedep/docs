**xBom** generates a Bill of Materials (BOM) of the AI components, cloud services and cryptography that your code uses. It finds them with static code analysis, not from your declared dependencies.

<Note>
  For an SBOM or an AI BOM, use vet: see [Generate an SBOM](/governance/cyclonedx-sbom) and [Detect Shadow AI in Code](/governance/shadow-ai-detection). Vet uses the same code analysis with more signatures, and writes the AI BOM and the dependency SBOM in one CycloneDX file. Use xBom when you want only the components that code analysis finds, without a dependency scan.
</Note>

## Installation

Install xBom using one of the following methods:

**Homebrew (macOS, and Linux on x86_64):**

```bash
brew install safedep/tap/xbom
```

**Pre-built binary:**
Download a **[pre-built binary](https://github.com/safedep/xbom/releases)** for your operating system from the GitHub releases page.

**Container image:** the image starts `xbom` as its entrypoint. Mount the code into the container:

```bash
docker run --rm -v "$PWD:/src" ghcr.io/safedep/xbom generate --dir /src --bom /src/bom.cdx.json
```

## Generating Your First BOM

To generate a BOM for your source code, use the `generate` command:

```bash
xbom generate --dir /path/to/your/code --bom /path/to/output/bom.cdx.json
```

Replace `/path/to/your/code` with your project directory and `/path/to/output/bom.cdx.json` with your desired output path. `--dir` defaults to the current directory. Without `--bom`, xBom shows only a summary.

The output is an SBOM in **[CycloneDX v1.6 JSON format](https://cyclonedx.org/docs/1.6/json/)**, including any AI components and other supported elements detected in the codebase.

## Supported Languages

xBom supports Python and Java. JavaScript support is partial.

## Supported BOM Types

xBom identifies components beyond traditional libraries:

- **AI SDKs and services:** LangChain, Anthropic, CrewAI and OpenAI
- **Cloud services:** Google Cloud Platform (GCP), including Pub/Sub, and Microsoft Azure, including Service Bus
- **Other:** cryptography libraries and Microsoft Office integrations

## HTML report

The primary output is a CycloneDX JSON file. To browse the detected components in a browser, also write an HTML report:

```bash
xbom generate --dir /path/to/your/code --bom bom.cdx.json --html report.html
```

## Telemetry

`xbom` collects anonymous usage telemetry to show which integrations and use cases are common, guiding what to build next. It collects no personally identifiable information or sensitive data.

To turn telemetry off, set the `XBOM_DISABLE_TELEMETRY` environment variable to `true`:

```bash
export XBOM_DISABLE_TELEMETRY=true
```
