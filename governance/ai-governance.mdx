title: AI Governance
description: "Inventory the AI libraries and SDKs your applications use with an AI BOM generated from source code."
---

Developers add AI libraries, SDKs, and agent frameworks to application code without central tracking. Security and compliance teams end up with no inventory of the AI services the code actually calls.

An **AI BOM** (AI Bill of Materials) closes that gap. `vet` analyzes your source code, detects calls to known AI SDKs, and writes each detection into a [CycloneDX](/concepts/sbom) BOM with file and line evidence.
