[Vet](https://github.com/safedep/vet) is a free, open-source software composition analysis (SCA) scanner. It checks your open-source dependencies for malicious packages, known vulnerabilities, license issues, and weak project health, then lets you enforce policy on what it finds. Run it locally, in CI/CD, or against a whole repository.

## What Vet does

- **Scans many sources.** A directory, a lockfile or an SBOM. Vet also scans container images, GitHub repositories and organizations, one package by its PURL, VS Code extensions, Homebrew packages and Agent Skills.
- **Uses SafeDep package intelligence.** Vulnerabilities from OSV, OpenSSF Scorecard data and malicious package analysis.
- **Enforces policy as code.** Write and version the policy with [CEL](/concepts/cel). Vet can fail a build when a package breaks the policy.
- **Writes the report that you need.** SARIF, JSON, Markdown, CSV, HTML, CycloneDX, GitLab, Bitbucket Code Insights and DefectDojo. Vet can also sync the results to SafeDep Cloud.
