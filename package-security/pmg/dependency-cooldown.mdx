---
title: "Hold Back Newly Published Package Versions"
description: "Set how many days PMG waits before it installs a newly published package version, and exempt the packages you trust."
---

An attacker who takes over a maintainer account publishes a malicious version. The registry often removes the version within days. The PMG dependency cooldown hides each version that is younger than a set number of days, so the package manager installs an older version.

The cooldown is on by default with a window of 2 days. It applies to npm, PyPI, Go, and Cargo packages.

## Set the window

```bash
pmg config set dependency_cooldown.days 7
```

To turn the cooldown off, set `dependency_cooldown.enabled` to `false`.

## Read the result

When the version range allows an older version, the package manager installs it and PMG shows no message. PMG blocks the install in these cases:

- Every version of the package is inside the window.
- You asked for an exact version, such as `pmg npm install pkg@1.2.3`, and that version is inside the window.

The report starts with `Dependency cooldown` and names each blocked package. When a dependency asks for an exact version inside the window, the package manager fails, and PMG lists the held-back versions after the error. Add `--verbose` to see the held-back versions on every install.

The cooldown filters the list of versions that the registry sends. It does not apply when the package manager downloads a locked version directly, such as `npm ci` with a lockfile. Cargo is the exception. PMG checks each download from a `Cargo.lock` against the window.

## Exempt a package

For a package that you must install as soon as it is published, such as your own SDK, add it to the skip list. Open the config file with `pmg config edit` and add an entry:

```yaml
dependency_cooldown:
  enabled: true
  days: 7
  skip:
    - purl: pkg:npm/my-internal-sdk
      reason: "First-party SDK, tested on release"
    - purl: pkg:npm/another-internal-pkg@1.2.3
      reason: "One build we must test now"
```

A package URL (PURL) without a version exempts all versions. A PURL with a version exempts only that version. PMG still checks an exempt package for malware.

## Skip the cooldown for one install

```bash
pmg --skip-dependency-cooldown npm install express
```
