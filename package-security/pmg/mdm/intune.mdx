---
title: "Intune"
description: "Deploy PMG to macOS or Linux devices with a single-script Microsoft Intune shell-script policy."
---

Intune accepts one shell script per policy, and it has no script parameters. Generate a [standalone installer](https://github.com/safedep/pmg/tree/main/scripts/mdm/standalone) for your platform with your SafeDep Cloud credentials embedded, then upload that file.

<Note>
  A [SafeDep subscription](https://safedep.io/pricing) is required to sync PMG events with SafeDep Cloud.
</Note>

You need a SafeDep Cloud API key and Tenant ID from [app.safedep.io/settings/api-keys](https://app.safedep.io/settings/api-keys). Installs sync to [Package Guard](/governance/cloud/endpoint-hub/package-guard).

## Install

1. Clone [pmg](https://github.com/safedep/pmg) and generate the installer from `scripts/mdm/`:

   <Tabs>
     <Tab title="macOS">
       ```sh
       SAFEDEP_API_KEY=... SAFEDEP_TENANT_ID=... \
         ./generate_standalone_macos.sh \
         --embed-cloud-credentials \
         --output-dir /path/to/pmg-intune
       ```
     </Tab>
     <Tab title="Linux">
       ```sh
       SAFEDEP_API_KEY=... SAFEDEP_TENANT_ID=... \
         ./generate_standalone_linux.sh \
         --embed-cloud-credentials \
         --output-dir /path/to/pmg-intune
       ```
     </Tab>
   </Tabs>

   You can optionally add `--config /path/to/config.yml` to package a machine-wide config. Set `cloud.enabled: true` in that file.

<Warning>
  Base64 is not encryption. Anyone who can read the uploaded installer in Intune can recover the credentials. Use a scoped, revocable API key. Do not commit the generated artifacts.
</Warning>

2. Upload the generated installer through Intune, using the procedure for your platform:

   <Tabs>
     <Tab title="macOS">
       Follow [Microsoft's procedure for macOS shell scripts](https://learn.microsoft.com/en-us/intune/device-management/tools/run-shell-scripts-macos). Upload `pmg_setup_install_macos_standalone.sh`. Set **Run script as signed-in user** to **No**.
     </Tab>
     <Tab title="Linux">
       In the Intune admin center:

       - Go to **Devices > Manage devices > Scripts and remediations > Platform scripts**.
       - Select the **Linux** tab and add `pmg_setup_install_linux_standalone.sh`.
       - Set the execution context to **Root**.

       See [Microsoft's procedure for Linux shell scripts](https://learn.microsoft.com/en-us/intune/intune-service/configuration/custom-settings-linux).
     </Tab>
   </Tabs>

3. Assign the policy to a device group, with a recurring install frequency. Install now runs `pmg cloud sync` for every target user each time, so a user who signs in later gets synced on the next run. Only a signed-in user can receive stored Cloud credentials during that run.

   Intune scripts take no runtime parameters, so `--cloud-sync-only` is not available here. The recurring install covers the same need.

The generated script stays under Intune's 1 MB size limit.

## Uninstall

Upload the matching uninstaller from the same output directory (`pmg_uninstall_macos_standalone.sh` or `pmg_uninstall_linux_standalone.sh`), with the same platform settings as install. Do not assign the install and uninstall policies at the same time.
