---
title: "Deploy PMG with MDM"
description: "Install PMG on macOS fleets through Jamf, JumpCloud, Intune, or any MDM that can run a shell script as root."
---

Install or remove PMG on macOS devices through your MDM so package installs go through PMG.

<Note>
  The [MDM scripts README](https://github.com/safedep/pmg/blob/main/scripts/mdm/README.md) in the PMG repo is the source of truth. Scripts and supported MDMs land there first.
</Note>

macOS only. For Linux images and shared VMs, use [system install](/package-security/pmg/system-install).

## Supported MDMs

<CardGroup cols={3}>
  <Card title="Jamf" icon="apple" href="/package-security/pmg/mdm/jamf">
    Multi-file scripts. Pass cloud credentials as script parameters.
  </Card>
  <Card title="JumpCloud" icon="cloud" href="/package-security/pmg/mdm/jumpcloud">
    Multi-file scripts, attached to a Command that runs as root.
  </Card>
  <Card title="Intune" icon="microsoft" href="/package-security/pmg/mdm/intune">
    One standalone script per policy.
  </Card>
</CardGroup>

Mosyle, Kandji, and other MDMs that run a shell script as root on macOS use the same scripts. Follow [Jamf](/package-security/pmg/mdm/jamf) or [JumpCloud](/package-security/pmg/mdm/jumpcloud) when your MDM can ship more than one file. Follow [Intune](/package-security/pmg/mdm/intune) when it accepts one script per policy.

## Scripts

- **Multi-file** (Jamf, JumpCloud): deploy `lib_macos.sh` with `pmg_setup_install_macos.sh` or `pmg_uninstall_macos.sh`.
- **Standalone** (Intune): use the scripts in [`standalone/`](https://github.com/safedep/pmg/tree/main/scripts/mdm/standalone).

Optional `config.yml` and cloud credentials are covered in the [README](https://github.com/safedep/pmg/blob/main/scripts/mdm/README.md).
