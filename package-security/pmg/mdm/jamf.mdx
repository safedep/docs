---
title: "Jamf"
description: "Deploy PMG to macOS devices with a Jamf script payload or package."
---

Deploy PMG with a Jamf policy that runs the [multi-file MDM scripts](https://github.com/safedep/pmg/tree/main/scripts/mdm/macos) as root. Ship `lib_macos.sh` with the install or uninstall script.

Jamf manages Apple devices only. For a Linux or Windows fleet, use [JumpCloud](/package-security/pmg/mdm/jumpcloud) or [Intune](/package-security/pmg/mdm/intune) instead.

<Note>
  Cloud sync is optional. For the plan, the API key and the Tenant ID, see [Cloud sync](/package-security/pmg/mdm/overview#cloud-sync).
</Note>

## Install

1. Download `lib_macos.sh` and `pmg_setup_install_macos.sh` from [`scripts/mdm/macos/`](https://github.com/safedep/pmg/tree/main/scripts/mdm/macos).

   You can optionally add a sibling `config.yml` for a machine-wide config. If you do, set `cloud.enabled: true` in it. A global config prevents the installer from changing that flag.
2. Upload the folder as a script payload, or as a package that drops the files together at a fixed path.
3. Create a policy that runs as root and invokes the installer. Pass the Cloud credentials as Jamf script parameters `$4` and `$5`:

   ```sh
   #!/bin/sh
   cd "$(dirname "$0")"
   SAFEDEP_API_KEY="$4" SAFEDEP_TENANT_ID="$5" ./pmg_setup_install_macos.sh
   ```

   Renumber `$4` and `$5` if your parameter slots differ.
4. Assign the policy to a computer group and run it.

## Uninstall

Create a second policy with `lib_macos.sh` and `pmg_uninstall_macos.sh`:

```sh
#!/bin/sh
cd "$(dirname "$0")"
./pmg_uninstall_macos.sh
```

Assign it to the same computer group. Do not run the install and uninstall policies on the same devices at the same time.

## Run cloud sync only

Create a separate policy to repeat cloud sync without installing or configuring PMG again. Reuse the install script and parameters, and add `--cloud-sync-only`:

```sh
#!/bin/sh
cd "$(dirname "$0")"
SAFEDEP_API_KEY="$4" SAFEDEP_TENANT_ID="$5" ./pmg_setup_install_macos.sh --cloud-sync-only
```

Assign this policy to the same computer group with a recurring trigger. Use it only for users who already have PMG and cloud sync enabled. Run the normal install policy to configure new users.

## Manage settings from the cloud policy

To let SafeDep Cloud set the package rules and the dependency cooldown, ship a managed `config.yml` with `cloud.policy: true`. See [Manage settings from the cloud policy](/package-security/pmg/mdm/overview#manage-settings-from-the-cloud-policy).
