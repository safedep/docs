---
title: "JumpCloud"
description: "Deploy PMG to macOS, Linux, or Windows devices with JumpCloud Commands."
---

Deploy PMG with a JumpCloud Command that runs as root on macOS or Linux, or as SYSTEM on Windows. Use the [multi-file MDM scripts](https://github.com/safedep/pmg/tree/main/scripts/mdm) and ship the shared lib with the install or uninstall script for your platform.

<Note>
  A [SafeDep subscription](https://safedep.io/pricing) is required to sync PMG events with SafeDep Cloud.
</Note>

For optional Cloud sync, you need a SafeDep Cloud API key and Tenant ID from [app.safedep.io/settings/api-keys](https://app.safedep.io/settings/api-keys). Installs sync to [Package Guard](/governance/cloud/endpoint-hub/package-guard).

## Install

<Steps>
  <Step title="Create a Command">
    In the JumpCloud Admin Console, create a Command and set **Run As** to `root` for macOS or Linux. Windows Commands run as SYSTEM.
  </Step>
  <Step title="Attach the scripts">
    <Tabs>
      <Tab title="macOS">
        Upload `lib_macos.sh` and `pmg_setup_install_macos.sh` from [`scripts/mdm/macos/`](https://github.com/safedep/pmg/tree/main/scripts/mdm/macos).
      </Tab>
      <Tab title="Linux">
        Upload `lib_linux.sh` and `pmg_setup_install_linux.sh` from [`scripts/mdm/linux/`](https://github.com/safedep/pmg/tree/main/scripts/mdm/linux).
      </Tab>
      <Tab title="Windows">
        Upload `lib_windows.ps1` and `pmg_setup_install_windows.ps1` from [`scripts/mdm/windows/`](https://github.com/safedep/pmg/tree/main/scripts/mdm/windows). Optionally include `pmg.exe` from the [v0.29.0 release zip](https://github.com/safedep/pmg/releases/tag/v0.29.0), owned by Administrators or SYSTEM, to avoid a download.
      </Tab>
</Tabs>
    Use **File Destination** `/tmp/pmg-mdm/` on macOS and Linux, or `C:\Windows\Temp\pmg-mdm\` on Windows. You can also upload a `config.yml` alongside the scripts for managed config. To enable Cloud sync, set `cloud.enabled: true` in it. This config is required for Windows Cloud sync, since the installer always creates a managed config.
  </Step>
  <Step title="Set the timeout">
    Set **Timeout After** to at least 900 seconds so a slow download is not killed mid-run.
  </Step>
  <Step title="Add Cloud variables">
    Define the Command Variables `safedep_api_key` and `safedep_tenant_id`. Mark the API key as a Secret variable. For local-only blocking, omit both variables and their assignments from the Command body.
  </Step>
  <Step title="Set the Command body">
    <Tabs>
      <Tab title="macOS">
        ```sh
        #!/bin/sh
        set -eu
        cd /tmp/pmg-mdm
        chmod +x pmg_setup_install_macos.sh
        SAFEDEP_API_KEY={{safedep_api_key}} SAFEDEP_TENANT_ID={{safedep_tenant_id}} ./pmg_setup_install_macos.sh
        cd / && rm -rf /tmp/pmg-mdm
        ```
      </Tab>
      <Tab title="Linux">
        ```sh
        #!/bin/sh
        set -eu
        cd /tmp/pmg-mdm
        chmod +x pmg_setup_install_linux.sh
        SAFEDEP_API_KEY={{safedep_api_key}} SAFEDEP_TENANT_ID={{safedep_tenant_id}} ./pmg_setup_install_linux.sh
        cd / && rm -rf /tmp/pmg-mdm
        ```
      </Tab>
      <Tab title="Windows">
        ```powershell
        $env:PMG_VERSION = 'v0.29.0'
        $env:SAFEDEP_API_KEY = '{{safedep_api_key}}'
        $env:SAFEDEP_TENANT_ID = '{{safedep_tenant_id}}'
        & C:\Windows\Temp\pmg-mdm\pmg_setup_install_windows.ps1
        ```

        The version pin selects PMG v0.29.0. Without a pin, the installer downloads the latest stable release. See [Windows version requirements](/package-security/pmg/mdm/overview#windows-deployment-checks).
      </Tab>
    </Tabs>
  </Step>
  <Step title="Assign and run">
    Assign the Command to a device group and run it.
  </Step>
</Steps>

On Windows, run the [deployment checks](/package-security/pmg/mdm/overview#windows-deployment-checks) in a new terminal after install. Only logged-on users receive Cloud credentials and sync.

## Uninstall

<Steps>
  <Step title="Create a second Command">
    Use root on macOS or Linux, or SYSTEM on Windows.
    <Tabs>
      <Tab title="macOS">
        Upload `lib_macos.sh` and `pmg_uninstall_macos.sh` from [`scripts/mdm/macos/`](https://github.com/safedep/pmg/tree/main/scripts/mdm/macos), with **File Destination** `/tmp/pmg-mdm/`.
      </Tab>
      <Tab title="Linux">
        Upload `lib_linux.sh` and `pmg_uninstall_linux.sh` from [`scripts/mdm/linux/`](https://github.com/safedep/pmg/tree/main/scripts/mdm/linux), with **File Destination** `/tmp/pmg-mdm/`.
      </Tab>
      <Tab title="Windows">
        Upload `lib_windows.ps1` and `pmg_uninstall_windows.ps1` from [`scripts/mdm/windows/`](https://github.com/safedep/pmg/tree/main/scripts/mdm/windows), with **File Destination** `C:\Windows\Temp\pmg-mdm\`.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Set the Command body">
    <Tabs>
      <Tab title="macOS">
        ```sh
        #!/bin/sh
        set -eu
        cd /tmp/pmg-mdm
        chmod +x pmg_uninstall_macos.sh
        ./pmg_uninstall_macos.sh
        cd / && rm -rf /tmp/pmg-mdm
        ```
      </Tab>
      <Tab title="Linux">
        ```sh
        #!/bin/sh
        set -eu
        cd /tmp/pmg-mdm
        chmod +x pmg_uninstall_linux.sh
        ./pmg_uninstall_linux.sh
        cd / && rm -rf /tmp/pmg-mdm
        ```
      </Tab>
      <Tab title="Windows">
        ```powershell
        & C:\Windows\Temp\pmg-mdm\pmg_uninstall_windows.ps1
        ```

        Complete the [Windows user cleanup steps](/package-security/pmg/mdm/overview#windows-deployment-checks) before removal.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Assign and run">
    Assign the Command to the same device group and run it. Do not run the install and uninstall Commands on the same devices at the same time.
  </Step>
</Steps>

## Run cloud sync only

Create another Command to repeat cloud sync without installing or configuring PMG again. Set it up the same way as the install Command, with the same shared library and script and root on macOS/Linux or SYSTEM on Windows. Use this Command body:

<Tabs>
  <Tab title="macOS">
    ```sh
    #!/bin/sh
    set -eu
    cd /tmp/pmg-mdm
    chmod +x pmg_setup_install_macos.sh
    SAFEDEP_API_KEY={{safedep_api_key}} SAFEDEP_TENANT_ID={{safedep_tenant_id}} ./pmg_setup_install_macos.sh --cloud-sync-only
    cd / && rm -rf /tmp/pmg-mdm
    ```
  </Tab>
  <Tab title="Linux">
    ```sh
    #!/bin/sh
    set -eu
    cd /tmp/pmg-mdm
    chmod +x pmg_setup_install_linux.sh
    SAFEDEP_API_KEY={{safedep_api_key}} SAFEDEP_TENANT_ID={{safedep_tenant_id}} ./pmg_setup_install_linux.sh --cloud-sync-only
    cd / && rm -rf /tmp/pmg-mdm
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    $env:SAFEDEP_API_KEY = '{{safedep_api_key}}'
    $env:SAFEDEP_TENANT_ID = '{{safedep_tenant_id}}'
    & C:\Windows\Temp\pmg-mdm\pmg_setup_install_windows.ps1 --cloud-sync-only
    ```

    Only logged-on users are synced. This mode does not save credentials in Credential Manager; rerun the normal installer to store them after users sign in.
  </Tab>
</Tabs>

Assign it to the same device group on a recurring schedule. Use it only for users who already have PMG and cloud sync enabled. Run the normal install Command to configure new users.
