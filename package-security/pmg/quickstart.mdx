**Package Manager Guard (PMG)** wraps your package manager and blocks malicious packages at install time.

<Info>
  PMG requires **no configuration** - just install and use it as you normally
  would with your package managers.
</Info>

For what PMG is and how it works, see the [PMG overview](/package-security/pmg/overview).

## Installation

### Using Homebrew (macOS and Linux)

```bash
brew install safedep/tap/pmg
```

### Using Go Install

```bash
go install github.com/safedep/pmg@latest
```

### Download Binary

Download the latest release from our [GitHub releases page](https://github.com/safedep/pmg/releases) and add it to your PATH.

### Windows

Use Windows 10 or 11. Download `pmg_Windows_x86_64.zip` from [v0.29.0](https://github.com/safedep/pmg/releases/tag/v0.29.0), extract `pmg.exe`, and add its directory to your PATH. The release is x86-64 only. ARM64 runs it under emulation. 32-bit Windows is not supported.

Windows support requires PMG v0.29.0 or later.

For Node.js installed by its MSI, winget, or Chocolatey, use the [Windows system install](/package-security/pmg/system-install#windows-machines). These installers put Node on the machine PATH, ahead of every per-user shim. Until system install is complete, invoke `pmg npm` explicitly.

## Quick Setup

### Automated Setup (Recommended)

Run PMG's automated setup:

```sh
pmg setup install
```

<Tabs>
  <Tab title="macOS and Linux">
    Setup creates package-manager PATH shims and the `~/.pmg.rc` alias layer for bash, zsh, and fish. Restart your terminal or source your shell's config file to activate it.
  </Tab>
  <Tab title="Windows">
    Setup creates `.cmd` shims in `%LOCALAPPDATA%\safedep\pmg\bin` and prepends that directory to your user PATH. It does not create aliases or PowerShell profile functions. Open a new PowerShell or `cmd.exe` terminal.

    ```powershell
    Get-Command npm
    pmg setup doctor
    ```

    `npm` should resolve under the shim directory. If the real manager appears first, follow the diagnostic and use [system install](/package-security/pmg/system-install#windows-machines) for machine-wide toolchains.
  </Tab>
</Tabs>

Verify protection with the benign test package. PMG must block it:

```sh
npm install --no-cache --prefer-online safedep-test-pkg@0.1.3
```

### Manual Usage (Alternative)

To invoke PMG explicitly:

```bash
pmg npm install <package-name>
pmg pnpm add <package-name>
pmg pip install <package-name>
```

If PMG detects a malicious package, it blocks the install and displays a warning.

## Supported Package Managers

PMG supports these tools from the [PMG README](https://github.com/safedep/pmg#supported-package-managers):

| Package Manager | Status | Command |
| --------------- | ------ | ------- |
| `npm` | Active | `pmg npm install <package>` |
| `pnpm` | Active | `pmg pnpm add <package>` |
| `yarn` | Active | `pmg yarn add <package>` |
| `bun` | Active | `pmg bun add <package>` |
| `aube` | Active | `pmg aube add <package>` |
| `npx` | Active | `pmg npx <package>` |
| `pnpx` | Active | `pmg pnpx <package>` |
| `aubx` | Active | `pmg aubx <package>` |
| `aubr` | Active | `pmg aubr <script>` |
| `pip` | Active | `pmg pip install <package>` |
| `pipx` | Active | `pmg pipx run <package>` |
| `poetry` | Active | `pmg poetry add <package>` |
| `uv` | Active | `pmg uv add <package>` or `pmg uv pip install <package>` |
| `uvx` | Active | `pmg uvx <package>` |

<Note>
  The aube tools (`aube`, `aubx`, and `aubr`) are not part of the initial Windows support. See the [Windows support reference](https://github.com/safedep/pmg/blob/main/docs/windows-support.md#supported-package-managers).
</Note>

## Troubleshooting

### If PMG isn't working after setup

1. Restart your terminal
2. On macOS or Linux, run `type npm` to check for a PMG alias or shim. If it resolves to the real manager, run `pmg setup install` again and restart the terminal.
3. On Windows, run `Get-Command npm` in PowerShell. It should resolve under `%LOCALAPPDATA%\safedep\pmg\bin` for a per-user setup, or `%ProgramFiles%\safedep\pmg\bin` for system install.
4. Run `pmg setup doctor` to check PATH, shims, and config, and `pmg version` to check the installed version.

### Windows coverage

Use PowerShell or `cmd.exe` for automatic interception. In Git Bash, invoke `pmg npm` or `pmg pip` explicitly. Run `pmg setup doctor` to diagnose setup problems.

See the [Windows support reference](https://github.com/safedep/pmg/blob/main/docs/windows-support.md) for PATH behavior, supported shells, WSL, and platform limitations.

### If packages are incorrectly blocked

1. Run with `--verbose` to see detection details
2. Check the [SafeDep community](https://discord.gg/kAGEj25dCn) for known issues
3. Report false positives on [GitHub Issues](https://github.com/safedep/pmg/issues)
