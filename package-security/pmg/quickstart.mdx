After setup, you run `npm install` and `pip install` as before, and PMG checks each package.

## Prerequisites

- macOS, Linux, or Windows 10 or 11. On Windows, use PMG v0.29.0 or later. The Windows release is x86-64 only. Windows 11 on ARM64 runs it through emulation.

## Install and verify

<Steps>
  <Step title="Install PMG">
    <Tabs>
      <Tab title="macOS and Linux">
        ```bash
        curl -fsSL https://raw.githubusercontent.com/safedep/pmg/main/install.sh | sh
        ```

        The script checks the SHA-256 checksum of the release. You can also use Homebrew:

        ```bash
        brew install safedep/tap/pmg
        ```
      </Tab>
      <Tab title="Windows">
        Download `pmg_Windows_x86_64.zip` from the [latest release](https://github.com/safedep/pmg/releases/latest). Extract `pmg.exe` and add its directory to your `PATH`.

        To protect every user of the machine, use the MSI or Chocolatey from an administrator terminal instead. They run the machine-wide setup, so skip the next step. See [Windows machines](/package-security/pmg/system-install#windows-machines).
      </Tab>
    </Tabs>

    For npm, mise, `go install`, and binary downloads, see [Installation](https://github.com/safedep/pmg#installation) in the PMG README.
  </Step>
  <Step title="Set up your shell">
    ```bash
    pmg setup install
    ```

    Open a new terminal. On macOS and Linux, setup adds PATH shims and the `~/.pmg.rc` alias layer for bash, zsh, and fish. On Windows, it adds `.cmd` shims in `%LOCALAPPDATA%\safedep\pmg\bin` first on your user `PATH`.
  </Step>
  <Step title="Check the setup">
    ```bash
    pmg setup doctor
    ```

    The doctor checks the shims, `PATH`, and the config.
  </Step>
  <Step title="Install a test package">
    ```bash
    npm install --no-cache --prefer-online safedep-test-pkg@0.1.3
    ```

    `safedep-test-pkg` is a benign package that SafeDep flags as malicious for tests. PMG must block it.
  </Step>
</Steps>

To run one command through PMG without the shims, add the `pmg` prefix, as in `pmg npm install express` or `pmg pip install requests`. In Git Bash on Windows, always use the prefix.

## Troubleshooting

- **The test package installs.** Run `type npm` on macOS or Linux, or `Get-Command npm` in PowerShell. If it resolves to the real package manager, run `pmg setup install` again and open a new terminal. On Windows, Node.js from the MSI, winget, or Chocolatey goes ahead of the per-user shims. Use the [Windows system install](/package-security/pmg/system-install#windows-machines) for it.
- **PMG blocks a package that you trust.** Run the command again with `--verbose` to see the detection details. Report a false positive on [GitHub Issues](https://github.com/safedep/pmg/issues).

For shells, WSL, and other Windows limits, see the [Windows support reference](https://github.com/safedep/pmg/blob/main/docs/windows-support.md).
