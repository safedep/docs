---
title: Path Exclusion
description: "Exclude specific directories and files from security scans using pattern matching"
---

Use the `--exclude` flag of `vet scan` to skip paths that match a pattern. This page covers `vet scan`. The `--exclude` flag of `vet code scan` takes Go regular expressions, not the glob patterns below.

vet always skips the `.git` and `node_modules` directories. You do not need to exclude them.

## Basic Usage

vet resolves a relative pattern against the current directory, not against the `-D` target. Run vet from the target directory:

```bash
cd /path/to/target
vet scan -D . --exclude 'docs/*'
```

## Multiple Exclusions

Specify multiple path patterns for exclusion:

```bash
vet scan -D . \
    --exclude 'docs/*' \
    --exclude 'sub/dir/path/*' \
    --exclude 'build/*'
```

<Info>
Exclusion patterns use [glob matching](https://github.com/bmatcuk/doublestar) (the `doublestar` library), not regular expressions. Use `*` to match within a single path segment and `**` to match across directories.
</Info>

`--exclude` also applies to the files that you give with `-M` and `--lockfiles`.

## Common Patterns

<Warning>
When a pattern matches a file, vet also skips the other files in the same directory. If the file is at the top of the scanned directory, vet scans nothing and shows no error. Until vet fixes this, exclude directories, not files, or check the number of scanned manifests.
</Warning>

Give each pattern to its own `--exclude` flag. A pattern without `**/` matches only at the top of the current directory.

| To skip | Patterns |
|---|---|
| Documentation and build output | `docs/*`, `build/*`, `dist/*`, `target/*`, `**/*.generated.*` |
| Tests | `test/*`, `tests/*`, `spec/*`, `**/*_test.go`, `**/*.test.js` |
| Installed dependencies | `vendor/*`, `.venv/*`, `**/__pycache__` |
| Editor and temporary files | `.idea/*`, `.vscode/*`, `**/*.log`, `tmp/*`, `temp/*` |
| File types in every directory | `**/*.md`, `**/*.txt`, `**/*.png`, `**/*.jpg` |
| Development-only files | `dev-tools/**`, `local-config/**`, `**/*.dev.*` |
| Code that does not ship to production | `test/*`, `examples/*`, `dev-dependencies/*` |
| Test and mock directories at any depth | `**/test/**`, `**/tests/**`, `**/spec/**`, `**/mocks/**` |
