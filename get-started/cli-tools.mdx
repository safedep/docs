SafeDep ships several command-line tools. Each one solves a different supply-chain problem, and they run independently, so you install only what you need. This page helps you pick the right tool and points you to its setup guide.

## The tools at a glance

| Tool | Solves | Needs an account? | Open source |
|---|---|---|---|
| **Vet** | Detect malicious and vulnerable dependencies in code and CI/CD | No (Cloud optional) | Yes |
| **PMG** | Block malicious packages at install time on the dev machine. It also has a [dependency cooldown](/package-security/pmg/dependency-cooldown), an opt-in [sandbox](/package-security/pmg/sandbox), and a [GitHub Action](/package-security/pmg/github-actions) for CI | No | Yes |
| **Gryph** | Local audit trail for AI coding agents. A policy can also block, warn, or guide an agent action | No (fully local) | Yes |
| [**xBom**](/governance/xbom/overview) | A standalone tool that generates a BOM of the AI, cloud and crypto components found in source code | No | Yes |
| **safedep** | Manage SafeDep Cloud from the terminal. This covers sign-in, the cloud policy, projects and labels, the audit log, endpoint telemetry queries, on-demand package scanning, AI agent protection, and integrations | Yes (SafeDep Cloud) | Yes |

<Note>
Vet, PMG, Gryph, and xBom are free, open source, and work with no SafeDep account. The **safedep** CLI is the client for SafeDep Cloud's hosted features. See [pricing](https://safedep.io/pricing).
</Note>

## How they relate

- **Vet** is the scanning engine. It analyzes dependencies and produces risk reports, queries, and SBOMs. It runs standalone, or in CI through [vet-action](https://github.com/safedep/vet-action) and the [pipeline integrations](/governance/integrations/overview). It can sync results to SafeDep Cloud.
- **PMG** and **Gryph** are standalone, single-purpose guards. PMG works at package-install time, Gryph around AI coding agents. Neither needs Vet or a SafeDep account.
- **safedep** is the CLI for SafeDep Cloud. It brings Cloud workflows to the terminal (sign-in, cloud policy, projects and labels, audit, [on-demand package scanning](/package-security/scan/overview), endpoint telemetry, AI agent protection, and integrations). It does not re-implement local scanning. Repository analysis stays in Vet, and on-demand package analysis runs in SafeDep Cloud.

<Info>
These tools have no "v1 to v2" relationship. `safedep` is a Cloud-focused CLI, not a replacement for `vet`. Vet stays the standalone scanner.
</Info>

## Install

Each tool is on the SafeDep Homebrew tap. Vet, PMG, Gryph, and safedep are also published to npm. Vet, PMG, Gryph, xBom, and safedep ship as pre-built binaries. The most common installs:

<Tabs>
  <Tab title="Homebrew">
    ```bash
    brew install safedep/tap/vet
    brew install safedep/tap/pmg
    brew install safedep/tap/gryph
    brew install safedep/tap/xbom
    brew install safedep/tap/cli   # the `safedep` command
    ```
  </Tab>
  <Tab title="npm">
    ```bash
    npm install -g @safedep/vet
    npm install -g @safedep/pmg
    npm install -g @safedep/gryph
    npm install -g @safedep/cli    # the `safedep` command
    ```
  </Tab>
</Tabs>

For every install method, current versions, and the full command surface, see the [Vet](https://github.com/safedep/vet), [PMG](https://github.com/safedep/pmg), [Gryph](https://github.com/safedep/gryph), and [safedep](https://github.com/safedep/cli) repositories.
